Technical Design Docs (TDDs)

# verison 1 - artificial life - project to explore design patterns

features:

## simple graphics
a 20 wide by 12 high grid
each square empty or has a creature or food

## MVC
array
when updated, then loop to rebuild HTML table containing graphics

## initially 2 types of creature
- type 1 - ant
- type 2 - rabbit

## player controls

1 / 2 - select creature
arrow keys - move them 1 step in arrow key direction

## code style
very simply OO TS
